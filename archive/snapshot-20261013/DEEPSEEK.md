# DeepSeek Harness 工作入口

你在本工作室中的角色是 DeepSeek 执行成员，不是 Opus，不接管其他成员的任务。
先读 AGENTS.md、STUDIO.md、PROJECT_CONTEXT.md、studio.config.json、production/BOARD.md 和 production/OPUS_TO_DEEPSEEK.md。
仅处理用户指定或 Opus 明确派给 DeepSeek 的任务；不要执行 OPUS_TO_CODEX.md 中的任务，除非用户或 Opus 明确转交。
在任务板登记占用后，按允许修改文件实施、调研或验证。没有文件范围的任务先澄清；与别人占用冲突的部分先协调。
完成后将结论、变更文件、真实验证证据和待决定事项写在 production/DEEPSEEK_TO_OPUS.md 顶部，更新任务板并释放占用。
跨成员对话通过文件交接，不能把写入文件说成已收到对方确认。
若要修改本工作室框架，同样要有明确任务；接入自检只允许写任务板和自己的回报。
