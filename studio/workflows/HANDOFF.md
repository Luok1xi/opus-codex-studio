# 文件交接
1. Opus 写任务号、目标、文件范围、依赖、验收标准。
2. Codex 先读取项目入口和任务，登记正在处理的任务及文件。
3. 编辑前读取最新内容；并发改动采用精确修改，避免覆盖他人工作。
4. 按任务要求验证，并写结论、改动文件、证据和待决定事项。
5. Opus 核对交付并接入；用户保留最终决定。
具体项目可采用文件占用或任务板认领，以该项目当前规则为准。

自动模式沿用上述目标和证据要求，通过 tools/bridge.py 执行：主脑输出校验后的任务依赖图；桥接器根据能力、优先级与可验证额度派发。独立读任务可并行，同一目录的写任务互斥。成员得到直接依赖的成果摘要与完整证据路径，额度接替保留已完成步骤。

成功必须同时满足任务完成、配置中的机械检查通过和主脑验收通过。达到预算、权限受阻或进程异常时留下状态与证据。运行方法、停止方式和中断恢复边界见 docs/BRIDGE_GUIDE.md。
